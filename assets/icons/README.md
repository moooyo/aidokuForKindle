# Interface icons

These are original SVG drawings implementing the familiar interface symbols shown
in the supplied design: books, compass, search, clock, settings, pagination, reading
controls, connectivity, and input. Each file uses a transparent 24-by-24 view box,
black paths, rounded caps and joins, and a two-unit stroke. They contain no text,
emoji, animation, external resources, scripts, or embedded raster images.

The application can recolor these icons for selected, disabled, or inverted controls.
Touch-target size is defined by the containing control, independently of icon size.

`source-unavailable.svg` is a fixed 132-by-132 blocked-source illustration. It uses
a 1.5-unit dashed circle, a 7-unit halftone pattern, a 64-unit white center, and a
34-unit warning glyph from the supplied handoff. Its pattern stays inside the
medallion and retains its monochrome fills rather than using control recoloring.
