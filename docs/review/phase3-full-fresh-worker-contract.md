# Fresh full-round visual worker contract

Each assignment is one small job in a new `fork_turns=none` context. Do not spawn another worker or continue an image queue after completing the assigned job.

Use Chinese for conversation and progress. Write code, comments, documentation and the compact review JSON in English. The host is Windows and shell commands must be valid PowerShell.

## Allowed work

Read local frozen evidence, scope, plan, contracts and supplied source-reference text statically. Use `tools.view_image` to open the assigned original PNGs. Read the UI/UX Pro Max skill when first applying it, announce that in Chinese, and do not run its search program.

Do not run a local or remote application, test, build, probe, validator, SQL query or hash command. Do not use SSH, copy files, process/crop images, modify production/harness/plan files, change captured originals or existing reports, create pull requests, or send messages outside internal collaboration.

## Identity and image budget

Use only the exact new run/source/binary and paths in the small input. Bind the report to its immutable module or capture-only manifest SHA and owner evidence inventory. All declared file hashes come from the owner; do not claim a local rehash. Current production files and previous candidate PNGs are not evidence for the assigned frozen capture.

Open every assigned new original candidate and each necessary assigned original reference. Never substitute a contact sheet, mechanical PASS, state field, previous pixel verdict or old candidate for actual new-image viewing. At most four reference pairs and eight image opens are allowed in one job. Supplemental states without an independent exact reference must be labelled as related-contract comparisons.

References that Root has already inspected clearly may be cited with the prior actual-viewing record when the reference identity is unchanged; do not claim that such reuse is a new image opening. Open any comparison needed to make the current judgement. If a necessary detail is unreadable, keep that check pending and ask the coordinator for an owner-generated original-scale crop with source/output SHA, dimensions, ROI, scale/algorithm and command/owner. Do not generate a crop or exceed this worker's image budget.

Native PNGs normally use logical dimensions and original design references physical dimensions at factor two. Keep actual native dimensions. Stretch profiles have no independent exact reference and must not be resized to impersonate one.

## Review contracts

Compare visible hierarchy, actual geometry, fonts, rules, control bounds, clipping, folio allocation, markers and truthful operation feedback. Real titles, covers, counts, dates, capacities and provider content may differ; those differences do not waive geometry, legibility, missing affordances or false success.

Closed Reader is artwork only: no app footer, bookmark ribbon, page/status label, download notice, debug decoration or invisible footer-cycle behavior. Actual source-art borders or captions with declared source/oracle identity are not app chrome. Screenshots cannot qualify hidden hit regions, physical input, framebuffer/evdev rotation, physical sleep/wake, e-ink effects, performance or a genuine live-reader lease.

Root accepts truthful unavailable/fixed-on controls and manual orientation in place of unsupported sensor-follow. Do not invent hardware, authorization or other features to imitate enabled sample states. Actual content may drive sheet origins/heights. Odd-final span1 is valid; do not force a half-slot. Toast follows authoritative HANDOFF section 4.6 and is not redesigned merely for temporary caption overlap. A visible list glyph satisfies the current menu contract; unresolved tiny dots are not a new patch request. Dataset-specific observed tag capacity is not a universal profile baseline.

Separate direct static observations from what the existing action/state/fixture/oracle evidence supports. A successful mechanical assertion is not visual acceptance. A failed recipe or wrong expected state is not automatically a product defect. Do not invent unexecuted or aborted scope. Do not reopen unrelated completed historical repairs or add feature wishes.

## Compact output

Write only the new report path assigned in the input. Include batch/reviewer/round/run identity, immutable manifest/inventory hashes, freeze tuple, reviewed case IDs, reference viewing records and concise limitations. For every case retain exact original PNG/case JSON/state/metadata/action/log/reference SHA, actual viewing, a short concrete observation, intentional/capability checks and the bounded static verdict.

Do not copy entire inputs, model arrays, state/oracle dumps or base64 into the report. Immediately notify the coordinator of an evidence-backed new actionable issue, identity mismatch or unreadable detail with its actual trigger and original case/PNG/reference hashes. Keep uncertain cause or scope separate. Final output is a short count/report-path/finding summary, with no image embeds and no full-round or clean claim.
