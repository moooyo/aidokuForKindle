# Original navigation and persistent Fast captures

Captured on 2026-11-16 through ssh test-env. This source-bound supplemental
candidate restores the user's original icon-and-label bottom bar, top active
marker and original bar height. Fast retains a monochrome frame and exposes
manual clearing without changing the saved interval for other modes.

Four final desktop cases cover Paperwhite 5 and Scribe, navigation hit areas,
English night-mode Fast settings and preserved interval preferences. The native
navigation capture uses the same final installed application with isolated
demo data. Native Fast request traces are retained in the review evidence;
no screenshot-triggered refresh was used for those page-turn measurements.
